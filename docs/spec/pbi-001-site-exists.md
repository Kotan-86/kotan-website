## Issue

**承認状態: 承認済み(2026-09-22、PO)。承認範囲は受入基準 AC-1〜AC-17 の全体。**

## 目的(Why)

プロダクトゴール「初対面の人やオンライン上で交流する人が、僕自身の身の丈に合った前向きな印象形成をスムーズに構築できる状態にする」に対して、まず **サイトが実在し、相手の端末から見られる** ことが出発点になる。

- 内容が充実していても、URLを渡して開けない状態では印象形成は始まらない。存在を知ってもらうこと自体に価値がある。
- 本 PBI は walking skeleton である。「名前と一言」という最小の中身を、本番と同じ経路(Astro でビルド → GitHub Actions → GitHub Pages)で公開まで通す。以後の PBI(顔写真、主要リンク、価値観/About、コミュニケーション、いまの自分、アウトプット、私的な面、コンタクト)は、この土台の上に積み増す。
- 公開経路を最初に通しておくことで、「入社前の公開」([docs/spec/website.md](./website.md) の公開目標)に向けた残りの不確実性を、中身の制作だけに絞れる。

## 実現内容(What)

### 画面(ユーザーから見えるもの)

公開URL `https://kotan-86.github.io/kotan-website/` を開くと、**1画面だけ**のページが表示される。ページに載るのは次の2つの情報だけである。

1. **名前** — 「こーたん（齋藤 光貴）」を、ページの主見出しとして、最初に目に入る位置に置く。
2. **一言** — 名前のすぐ下に「割となんでもやりたいが、なんでも出来るわけじゃないジュニアエンジニア」を置く。

それ以外のセクション、画像、外部リンク、ナビゲーションは置かない。ブラウザのタブに表示されるページタイトルは「こーたんプロフィールサイト」とする。favicon は Astro 雛形の既定のままとし、差し替えない(既定の favicon が表示されることを許容する)。

見た目は、基調色 `#606da1` を使った最小限のものとする。凝った装飾やアニメーションは加えない。スマートフォンの縦画面からデスクトップの横長画面まで、同じ1画面が読める形で収まる。

### 公開のしくみ(ユーザーには見えないが、本PBIの成果物)

- 本リポジトリで、Astro(TypeScript)+ Tailwind CSS v4 のプロジェクトとして、開発サーバ起動・静的ビルドができる状態を作る。
- `main` ブランチへの push をきっかけに、GitHub Actions がビルドと GitHub Pages へのデプロイを自動で行う。PO が手作業でファイルをアップロードする必要はない。
- 公開URLのパス(`/kotan-website/`)配下で、CSS を含むすべての参照が壊れずに表示される。

### 本PBIでやらないこと

- 顔写真、主要リンク、および [docs/spec/website.md](./website.md) の第2〜7セクションの追加。
- OGP(SNSシェア時のタイトル・説明・画像)の作り込み。内容が [docs/spec/website.md](./website.md) で未決のため。
- 独自ドメインの設定、アクセス解析の導入、多言語対応。
- Markdown によるコンテンツ管理のしくみ。本PBIの文言は2つだけのため、しくみ化はしない。
- GitHub Pages の有効化操作そのもの(POの作業)。
