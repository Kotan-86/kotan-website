# kotan-website 仕様（種）

この文書は、デザイン・実装に入る前の合意事項をまとめたものである。詳細な文言・画像・リンク一覧は資料追加後に更新する。

## Why（なぜ）

- 内定同期・入社同期・社員との交流が増えるなかで、「私はこういう人間です」を自分の言葉と実績で伝えたい。
- 既存の `kotan-portfolio` の配色は残しつつ、デザインはリニューアルし、名刺代わりかつ人となりが伝わる個人サイトにする。
- 入社直後は価値観と人柄の比重が大きく、経験を積むにつれてアウトプット中心に厚くしていける形にしたい。

## What（何を）

### 読者

- 主: 内定同期 / 入社同期・社員
- 副: それ以外の知人・社外の人（転職訴求はしない）

### 伝えたい自己像

- 「割となんでもやりたいが、なんでも出来るわけじゃないジュニアエンジニア」
- 「こういうアウトプットをする人」と「こういう価値観の人」の両方
- 時間経過とともにアウトプットの比重が増えてよい

### トーン・ビジュアル

- 基調色: `#606da1`（`kotan-portfolio` 由来）。配色の導出元であり、値は変更しない。画面上に背景・文字色として直接見える形で残す必要はない（PBI-002 決定）
- ページ背景色: 基調色を白で 30% 混合した色（`color-mix(in srgb, var(--color-brand-primary) 30%, white)`、概算16進値 `#cfd3e3`）
- 本文色: `#4f5984`（基調色を黒で 82% 混合した色に相当）。ページ背景色とのコントラスト比は 4.55:1（4.5:1 以上を満たす）
- カードの背景色: 白（`#ffffff`。トークン `--color-card-background`）。ページ背景色の混合式（基調色を白で混合する式）において、基調色の割合を 0% にした色、すなわち混合に使う白そのもの。本文色とのコントラスト比は 6.786:1（4.5:1 以上を満たす）。用途は、セクション内のまとまりを載せるカードの面で、最初の利用はコミュニケーション節のサブセクション（[pbi-004-communication-section.md](./pbi-004-communication-section.md)、issue #3 の Q8 決定）
- 雰囲気: 親しみやすい温かさ ＋ 前向きさ
- レイアウト: 複数セクションの縦長1ページ
- 参考構成（見た目は別物）: [https://info-kotomin-owf9sr.laravel.cloud/](https://info-kotomin-owf9sr.laravel.cloud/)
- UI 資産は全部新規（portfolio は色・文言などの参照のみ）

### ページ構成（セクション）

1. **ヒーロー** … 丸型の顔写真（左）と、名前・一言（上記の自己像）（右）を、同じ高さのカラムに入れて上端・下端を揃え、左右に並べる。左右カラムの横幅の比率は固定しない（テキスト側を広く取ってよい）。右カラムのテキストは左揃え。名前「こーたん（齋藤 光貴）」は、幅 640px 以上では折り返さずに1行で表示し、幅 640px 未満では「こーたん」と「（齋藤 光貴）」の境界でだけ2行に分かれてよい（それぞれのまとまりの途中では改行しない）。名前の文字サイズは画面幅に応じて自動的に変わる。そのブロックの下に、**X / GitHub / Qiita / note の4件のSNSへの導線**を置き、4件のまとまりの左端をブロック全体の左端（＝顔写真の左端）に揃える。各導線は各社の公式ロゴ（4つとも同じ高さ）とサービス名テキストを持ち、新しいタブで開く。4件の並びは幅 640px を境に切り替わる。幅 640px 以上（1280px を含む）では、常に4件が横一列（1段）に並び、左から X → GitHub → Qiita → note の順になる。幅 639px 以下（375px を含む）では、2件ずつ2段に並び、上段が X・GitHub、下段が Qiita・note（それぞれ左から順に）になる。3件と1件のような不揃いな段にはしない。幅 640px 未満では、上から 顔写真 → 名前・一言 → SNS導線4件 の縦積みになり、テキストは左揃え。顔写真の掲載は確定事項とする（[pbi-003-hero-photo-and-sns-links.md](./pbi-003-hero-photo-and-sns-links.md)、issue #2 で実装済み）
2. **価値観 / About** … エンジニアとしての価値観・大事にしていること
3. **コミュニケーションってどういうもの** … ヒーローの後に置くセクションで、セクションの見出しは「僕のコミュニケーション方法」。よく使うコミュニケーション手段（日本語対応手話など）、音声中心の環境で起こりやすいつまずき、周囲にしてもらえると関わりやすいことを伝える。これに対応する3つのサブセクション「目に見えるコミュニケーション手段を使っています」「音声中心の環境では、こういうつまずきが起こりやすいです」「こうしてもらえると、お互い関わりやすいです」をこの順に置き、各サブセクションは、その見出しと3項目の箇条書きで構成する。サブセクションごとに白地のカード（上記「カードの背景色」）に載せ、すべての画面幅で縦一列に並べる。セクションの左端と最大幅はヒーローのブロックに揃える。箇条書きの文言は [pbi-004-communication-section.md](./pbi-004-communication-section.md)（issue #3）で確定しており、この文書には転記しない。詳細な調整依頼リストの全文転載は必須としない（要約を載せる。詳細への導線は必要になった時点で追加してよく、現時点では置いていない）
4. **いまの自分** … 経歴・インターン・研究・これから社会人としてのスタンス
5. **アウトプット** … 制作物・登壇・発表・学園祭などの仕組みづくり・研究など。カテゴリ分けできること。将来、記事 URL 追加で増えていく想定
6. **私的な面** … 趣味・興味・話しやすい話題（公開制限は特になし。内容は後日追記）
7. **コンタクト** … 連絡手段（転職・カジュアル面談 CTA は置かない）。役割分担として、**ヒーロー＝主要SNS 4件（X / GitHub / Qiita / note）への導線、コンタクト＝それ以外の連絡手段（メール等）**とし、コンタクト節にSNSを重複して置かない

### コンテンツ運用

- 本文・経歴・アウトプット一覧などは **Markdown（または同等のデータ）でメンテ**する
- 見た目・レイアウト・動きは Markdown に閉じ込めず、コンポーネント側で自由に表現する
- 将来オプション: note / Qiita などの URL を POST するだけでアウトプット一覧が更新される。反映は再デプロイ（数分遅れ）でよい。初期リリース必須ではない

### 技術方針（決定）

- スタック: **Astro**（TypeScript。インタラクションが必要な箇所のみ必要に応じて React 等を併用してよい）
- スタイリング: **Tailwind CSS v4**（`kotan-portfolio` と同じ構成に揃える）
- 出力: 静的サイトとしてデプロイできること
- ホスティング: **GitHub Pages**（決定）。GitHub Actions で `main` への push から自動ビルド・デプロイする
  - リポジトリは `Kotan-86/kotan-website`（プロジェクトページ）となるため、公開 URL は `https://kotan-86.github.io/kotan-website/`。Astro 側は `base: '/kotan-website/'` の設定が必要
- ドメイン: 初期は上記の無料サブドメインで公開。独自ドメインの取得は後日検討（対応する場合も静的ホストの前提は崩さない）
- リポジトリ: 本リポジトリ `kotan-website` に新規構築。`kotan-portfolio` は改修しない

### 公開目標

- **入社前の公開を目指す**（正確な入社日・締め切りは別途確定）
- 全セクションを同時に完成させるより、資料が揃った箇所から順次拡充してよい。ただし「ヒーロー／価値観・About／コミュニケーション／コンタクト」は初期公開に必須、「いまの自分／アウトプット／私的な面」は簡易版でも可とし、後から厚くする

### 参照資料（後日・詳細埋め用）

- サポーターズ記載プロフィール（経歴・自己PR・制作物・スキル・リンク）
- 「齋藤のコミュニケーションってどんなもの!」（コミュニケーション節の元資料）
- その他、ユーザーが後から渡す画像・文言・リンク

### 初期リリースでやらないこと

- 実装・デザイン本番制作（本仕様確定・資料充足の後）
- 記事 URL POST による自動更新（将来オプション）
- 転職活動向けの訴求セクション
- 多言語対応（現時点では日本語のみ想定）

## 未決・後続

- 私的な面の具体トピック（ヒーロー用写真は受領・掲載済みのため解消。[pbi-003-hero-photo-and-sns-links.md](./pbi-003-hero-photo-and-sns-links.md)）
