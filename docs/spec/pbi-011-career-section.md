## 目的(Why)

〔出典: issue #36 の Why〕

- 経歴は、どんなエンジニアキャリアを歩んできたかを、概要として伝えられる道具である。
- 閲覧者が、経歴から気になった部分を、各セクション(「これまで」「これから」などのページ)で深掘りして見ていくことで、こーたんのエンジニアキャリアを立体的に理解するきっかけにしたい。

プロダクトゴール([docs/product-goal.md](../product-goal.md))の「社内外でこーたんの仕事やスキルを知ろうとする人が、…現在のスキルや得意領域を具体的に把握できる状態にする」に対し、入口(トップ = 経歴のページ)で現在の立ち位置を示すことでつながる。

### 見た目

9. **活動歴に寄せた見た目**: 確認する幅で、見出し「経歴」はカードの外にあり、大きさ・太さ・色が「大学生/院生 時代の活動歴」の見出しと同じ。導入文はカードの外(見出しとカードの間)にある。項目は白地のカード1枚の上にあり、左に点が1つある(縦線は無い)。〔検証: PO確認〕
